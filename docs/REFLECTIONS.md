# Individual Reflections

Each member writes their own section in their own words (about 200–300 words). Do not use AI to
write this part.

Prompts to help:

- What did you build or test, and which commit shows it?
- One thing that went wrong, and how you found and fixed it.
- What you now understand about offline-first apps, operation IDs or locking that you did not before.
- How you checked work that came from an AI tool before trusting it.
- What you would do differently next time.
